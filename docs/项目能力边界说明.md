# 项目当前能力边界说明

本文档整理本项目当前已经具备的输入方式、网格与边界条件处理方式、NMR 求解与反演参数，以及使用时必须由研究人员确认的科学假设。当前代码主要服务于二维孔隙尺度 NMR 模拟和 2.5D 体积加权解释，不应直接表述为完整三维模拟。

## 1. 图像或几何输入方式

当前项目支持两类主要输入：程序生成的理想几何，以及已经完成分割的二维图像切片。

### 1.1 主入口控制文件

推荐从根目录运行：

```powershell
python Auto_NMR.py
```

主要参数集中在：

```text
simulation_control.py
```

通常只修改 `simulation_control.py`，不直接改主程序。输出默认写入：

```text
simulation_outputs/Auto_NMR_controlled/
```

### 1.2 理想三角孔几何输入

适用场景：

- 用两个三角形孔隙表示 large pore 和 small pore；
- 研究 drainage / imbibition 下饱和度、水相分布、孔喉连接与 T2 响应；
- 比较 coupled 和 uncoupled 模式；
- 生成 T2、T2-T2、D-T2 结果和组合图。

主要控制项在 `simulation_control.py`：

```python
"geometry": {
    "mode": "verified_triangle",
    "triangle_angles_deg": [60.0, 60.0, 60.0],
    "contact_angle_deg": 0.0,
    "process": "Drainage",
    "slice_path": None,
}
```

更完整的三角孔工作流在：

```text
advanced_tools/triangle_contact_angle_full_suite.py
advanced_tools/run_triangle_contact_angle_cases.py
advanced_tools/CA_Drain_and_imbi.py
```

可设置的几何和水分布相关变量包括：

- `triangle_angles_deg`：三角孔内角；
- `contact_angle_deg`：接触角；
- `processes`：`Drainage` 或 `Imbibition`；
- `target_saturations`：目标饱和度序列；
- `selected_rm_mode`：选择毛细半径 / 界面位置的模式；
- large / small pore 尺寸、深度、throat 长度和宽度，目前在代码配置类或脚本中定义。

边界说明：该输入不是直接读取 CT 图像，而是根据几何参数生成孔隙域、水相区域、气相区域和连接喉道。

### 1.3 已分割二维图像输入

适用场景：

- 输入玻璃珠、CT 切片或其他二维孔隙结构图像；
- 图像已经被分割成 solid / water / air / outside 等标签；
- 希望从已有水相分布直接计算 T2 衰减、T2 反演，以及快速 T2-T2 / D-T2 近似图。

脚本入口：

```powershell
$env:PYTHONPATH='.'
python advanced_tools/image_slice_simulation.py
```

默认输入：

```text
data/input/Result.tif
```

默认标签约定：

```text
255: solid
102: water
153: air
0: outside / container, 不参与模拟
204: unknown / interface label, 由脚本清理到最近的有效标签
```

主要控制项：

```python
"image_slice": {
    "enabled": True,
    "input_path": "data/input/Result.tif",
    "output_dir": "simulation_outputs/image_slice_Result",
    "pixel_size_um": 1.0,
    "solid_value": 255,
    "water_value": 102,
    "air_value": 153,
    "outside_value": 0,
    "unknown_values": [204],
    "smooth_radius_px": 2,
    "interface_sigma_px": 1.25,
    "max_grid_size": None,
    "run_t2": True,
    "run_t2_t2": True,
    "run_dt2": True,
}
```

图像输入流程：

1. 读取 `.tif` 标签图；
2. 将非有效标签清理到最近的有效相标签；
3. 可选 Gaussian 平滑相概率；
4. 可选形态学 opening / closing 清理孤立像素和小孔洞；
5. 保存清理后的 label 图和预览图；
6. 将水相像素构建为有限差分 / 图拉普拉斯求解域。

当前能力边界：

- 当前图像流程默认要求输入已经是分割后的标签图；
- 不负责从原始灰度 CT 自动确定阈值或 phase 数量；
- 不自动判断每个灰度值对应的物理相；
- 不生成新的 drainage / imbibition 饱和度状态；
- T2-T2 和 D-T2 在该图像切片脚本中是从 T2 响应导出的快速近似图，不等同于三角孔 strict PFG 复数 PDE 流程。

### 1.4 已有衰减数据 / 反演输入

`nmr_t2/` 模块可以对已有衰减数据表进行 NNLS 或 L-curve 反演、绘图和 Gaussian 分解。适用场景是已经有实验或模拟衰减曲线，只需要做 T2 反演和谱分析。

可处理内容包括：

- Excel workbook 中的多列衰减曲线；
- fixed alpha NNLS；
- L-curve 自动选 alpha；
- T2 谱和衰减拟合图；
- Gaussian peak decomposition。

这一路径不负责生成孔隙几何或求解 PDE。

## 2. 图像输入后的网格与边界条件划分

当前项目有两套不同的离散化逻辑：理想几何使用 pyGIMLi 三角网格，图像切片使用水相像素网格 / 图拉普拉斯。

### 2.1 三角孔几何的网格划分

理想三角孔和接触角案例使用 `pygimli.meshtools` 构造几何，再用 `mt.createMesh` 生成三角网格。

典型参数：

```python
mt.createMesh(geom, area=0.05, quality=34)
```

含义：

- `area` 控制单元面积上限，越小网格越细，计算成本越高；
- `quality` 控制三角网格质量；
- coupled 模式会把 large pore、throat、small pore 拼接成一个连通域；
- uncoupled 模式会分别对 large pore 和 small pore 求解，再按体积或面积加权合成信号。

当前边界 marker 约定：

```text
solid_wall: solid wall，施加 surface relaxivity rho
water_air_interface: 水-气内部界面，默认不施加 surface relaxivity
throat_or_connection: 孔体之间的连接或喉道
symmetry_or_no_flux: 对称或隔离 no-flux 边界
```

实际 PDE 中，当前主要通过 pyGIMLi Robin 条件在 marker `1` 上施加表面弛豫：

```python
bc = {"Robin": {1: rho * dt}}
```

需要注意：部分脚本中水-气界面可能用 marker `99`、喉道可能用 marker `100` 标记，但当前核心求解默认只对 marker `1` 施加 `rho`。水-气界面和喉道的物理处理需要在解释中明确，不应默认声称所有界面都具有独立边界参数。

### 2.2 图像切片的网格划分

图像切片流程不生成 pyGIMLi 三角网格，而是把 water 标签像素作为求解节点：

- water 像素是扩散与磁化强度演化域；
- water-water 相邻像素形成扩散连接；
- water-solid 或 water-outside 邻接边计入表面弛豫 sink；
- water-air 邻接边在当前图像脚本中不计入 solid surface sink；
- outside 区域不参与模拟。

主要空间参数：

- `pixel_size_um`：像素物理尺寸；
- `max_grid_size`：可选降采样上限，`None` 表示使用原始分辨率；
- `smooth_radius_px`：形态学清理尺度；
- `interface_sigma_px`：相概率平滑尺度。

当前图像脚本构造的是二维水相像素域。若后续论文或报告中需要体积解释，应明确说明是否采用了 2.5D 假设，例如用像素面积乘以统一厚度或仅比较归一化信号。

### 2.3 Coupled 与 uncoupled 的含义

uncoupled：

- 对每个独立孔体或水相连通分量单独求解；
- 分量之间没有交换通量；
- 总信号由各分量信号相加或按体积加权得到。

coupled：

- 在连通水相域或带 throat 的双孔域中统一求解扩散；
- 孔体之间的交换由几何连通和扩散自然产生；
- 如果图像中的水相本来就是断开的，那么 coupled 全域求解在数学上会接近 block-diagonal，结果可能与 uncoupled 非常接近。

## 3. 求解模拟与可设参数

当前主要模拟 Bloch-Torrey / 扩散弛豫形式下的 T2 响应，并在此基础上做 T2-T2、D-T2 或 T1 扩展。

### 3.1 核心物理参数

默认单位：

```text
length: um
time: ms
diffusion: um^2/ms
surface relaxivity: um/ms
```

当前默认值：

```python
D = 2.0                 # diffusion_um2_per_ms
T2B = 3000.0            # bulk_t2_ms
rho = 0.005             # surface_relaxivity_um_per_ms
dt = 2.0 或脚本内指定值
t_max = 2000.0 或脚本内指定值
```

这些不是普适物理常数。用于正式模拟前，必须由用户根据样品、流体、温度、磁场条件、岩石表面性质或文献依据确认。

### 3.2 当前 PDE 边界条件

当前 T2 求解的逻辑可概括为：

```text
初始条件: 水相区域内均匀磁化强度
扩散项: D * Laplacian(M)
体弛豫: -M / T2B
固体壁面: Robin sink, rho * M
孔体交换: coupled 模式中由 throat / 连通水相扩散产生
隔离边界: no-flux 或没有水相连接
```

可设或可扩展的边界问题：

- solid-wall surface relaxation：当前已支持，是主要的 `rho` 作用边界；
- water-air interface：当前多数流程默认不施加 surface relaxation，若要设置独立水-气弛豫参数，需要明确物理依据并扩展求解逻辑；
- rock-air interface：不属于水相求解域，一般不直接参与 NMR 水相磁化强度求解；
- throat / pore connection：通过几何连通控制交换强弱；
- outside / container：在图像脚本中排除或视为非水相边界；
- symmetry / no-flux：可用于隔离孔体或对称边界，但需要在几何 marker 中明确。

### 3.3 时间轴和数值步长

重要参数：

- `dt_ms`：PDE 时间步长；
- `t_max_ms`：最大演化时间；
- `times` / `te_axis`：记录信号的时间轴；
- D-T2 中的 `pde_dt_ms`：PFG 复数场演化的内部步长；
- `delta_ms`：PFG 梯度脉冲相关时间；
- `mixing_time_ms`：T2-T2 exchange 的 mixing time。

注意事项：

- 时间步太大可能导致数值误差或过度平滑；
- 时间轴太短会丢失长 T2 分量；
- 时间轴太稀会影响反演稳定性；
- T2-T2 和 D-T2 比一维 T2 更耗时，应先用较低分辨率测试。

### 3.4 T2 反演参数

当前支持：

- fixed alpha NNLS；
- L-curve 自动选择正则化参数；
- T2 谱范围和 bins 数量设置；
- Gaussian decomposition 后处理。

主要参数：

```python
"inversion": {
    "mode": "fixed",
    "alpha": 1.0,
    "image_mode": "l_curve",
}
```

以及模块配置中的：

```text
t2_min_ms
t2_max_ms
t2_bins
alpha_min / alpha_max / alpha_count
```

使用建议：

- 理想几何、低噪声或方法对比：可用 fixed alpha，便于复现实验；
- CT / 玻璃珠图像或噪声更强的数据：优先用 L-curve；
- alpha 越大，谱越平滑，但可能抹掉真实多峰；
- alpha 太小，谱可能出现振荡或假峰；
- 反演结果应结合衰减拟合残差、L-curve 指标和物理可解释性判断。

### 3.5 T2-T2 参数

主要参数：

```python
"t2_t2": {
    "t1_points": 25,
    "t2_points": 35,
    "bin_points": 35,
    "t_axis_min_ms": 1.0,
    "t_axis_max_ms": 10 ** 3.1,
    "bin_min_ms": 10 ** 0.5,
    "bin_max_ms": 10 ** 3.5,
    "mixing_time_ms": 30.0,
    "alpha": 0.05,
}
```

注意事项：

- `mixing_time_ms` 会显著影响 exchange map 的 off-diagonal 强度；
- `t1_points`、`t2_points`、`bin_points` 越多，计算和反演成本越高；
- 2D NNLS 反演病态性更强，alpha 选择要谨慎；
- 对图像切片脚本，当前 T2-T2 是快速近似，不应和严格 T2-store-T2 PDE exchange 完全等同。

### 3.6 D-T2 / PFG 参数

主要参数：

```python
"dt2": {
    "b_axis": [0.0],
    "b_log_min": -3.0,
    "b_log_max": 0.55,
    "b_log_points": 13,
    "te_min_ms": 25.0,
    "te_max_ms": 1300.0,
    "te_points": 24,
    "d_log_min": -3.0,
    "d_bin_scale_to_bulk_D": 1.5,
    "d_bins": 32,
    "t2_bin_min_ms": 10 ** 0.5,
    "t2_bin_max_ms": 10 ** 3.5,
    "t2_bins": 40,
    "delta_ms": 20.0,
    "pde_dt_ms": 8.0,
    "grad_axis": "y",
    "alpha": 0.025,
}
```

注意事项：

- `b_log_min`、`b_log_max`、`b_log_points` 控制 diffusion encoding 强度范围；
- `grad_axis` 控制梯度方向，目前常用 `x` 或 `y`；
- `delta_ms` 和 `pde_dt_ms` 影响 PFG 演化精度；
- `d_bins` 和 `t2_bins` 控制二维反演分辨率；
- D-T2 反演更容易受正则化和采样范围影响；
- 图像切片脚本中的 D-T2 是快速近似；三角孔 full suite 中包含更严格的 PFG 复数场演化。

### 3.7 T1 扩展

`advanced_tools/Auto_T1.py` 提供 T1 相关模拟。当前逻辑基于 T2 参数扩展，例如通过 `T1/T2` 比例设置 `T1B` 和 `rho1`。正式使用时需要确认：

- T1/T2 比例是否适用于样品；
- T1 surface relaxivity 与 T2 surface relaxivity 的关系是否有实验或文献依据；
- 是否需要独立校准 T1 和 T2 参数。

## 4. 当前主要能力与边界

当前可以做：

- 程序生成双三角孔几何；
- 接触角控制下的 drainage / imbibition 静态状态；
- 已分割二维图像切片输入；
- solid / water / air / outside 标签清理；
- coupled 与 uncoupled T2 响应比较；
- T2 衰减求解和 NNLS / L-curve 反演；
- T2-T2 exchange map；
- D-T2 / PFG map；
- T1 扩展模拟；
- 输出 Excel、PNG、PDF、JSON 等可复查结果；
- 保存部分运行配置和 summary 文件。

当前不能或不应自动完成：

- 从原始 CT 灰度图自动决定 phase 数量；
- 自动判断灰度阈值和每个 phase 的物理含义；
- 自动给出 surface relaxivity、diffusion coefficient、bulk relaxation 等关键物理参数；
- 自动判定某组参数足以支撑论文结论；
- 自动把二维结果称为三维结果；
- 对动态图像过程做真正的动态网格或强耦合动态求解；
- 对水-气界面、岩-气界面默认施加未经确认的独立边界条件；
- 对图像切片自动生成 Young-Laplace / minimum-energy 饱和度再分布。

## 5. 正式模拟前建议用户确认的信息

每次正式运行前，建议明确记录：

- 输入类型：理想几何、已分割图像、已有衰减曲线；
- 模型维度：2D、2.5D 或真实 3D；
- phase 标签和物理含义；
- `pixel_size_um` 或几何尺寸；
- 是否采用 drainage、imbibition 或单一静态状态；
- 接触角、目标饱和度、毛细半径或界面位置的来源；
- diffusion coefficient；
- bulk T1 / T2；
- solid-wall surface relaxivity；
- water-air interface 是否需要独立边界参数；
- 网格尺寸、降采样策略和计算成本；
- 时间步长、求解时间轴；
- fixed alpha 或 L-curve；
- T2-T2 mixing time；
- D-T2 b 值范围、梯度方向和 PFG 时间参数；
- 输出目录和是否需要保留中间文件。
