# Bundled Examples

This package includes one complete triangle-pore example and one segmented-image
example so a new user can inspect the expected output format before running new
simulations.

## Input CT / Glass-Bead Slice

Input file:

```text
data/input/Result.tif
```

Default label convention:

- `255`: solid
- `102`: water
- `153`: air
- `0`: outside/container, excluded from simulation
- `204`: unknown/interface label, cleaned by the script

Run the image-slice NMR workflow:

```powershell
$env:PYTHONPATH='.'
python advanced_tools/image_slice_simulation.py
```

Example output already included:

```text
examples/image_slice_Result/
```

This example shows:

- cleaned label image
- T2 decay and inversion
- L-curve vs fixed-alpha comparison
- coupled and uncoupled signal comparison
- T2-T2 map
- D-T2 map

## Triangle-Pore Example

Example output:

```text
examples/triangle_CA0deg_angles60-60-60/
```

Case definition:

- geometry: two equilateral triangular pores
- contact angle: `0 deg`
- inner angles: `60 / 60 / 60 deg`
- processes: drainage and imbibition
- modules: T2, T2-T2, D-T2, coupled and uncoupled
- component outputs: Large / Small / Total for uncoupled and coupled modes

This folder is arranged in the same format generated by
`organize_triangle_outputs.py`:

```text
00_metadata/
01_water_distribution/
02_T2/
03_T2_T2_exchange/
04_D_T2/
05_combined_panels/
06_effective_coupling_Zhou2026_GRL/
manifest.csv
README.md
```

Run a new triangle case:

```powershell
$env:PYTHONPATH='.'
python advanced_tools/run_triangle_contact_angle_cases.py --contact-angles 0 30 45 --triangle-angles 60 60 60
```

New results will be written to `simulation_outputs/`.

For coupled/uncoupled comparison, inspect:

```text
02_T2/tables/
02_T2/combined/
03_T2_T2_exchange/
04_D_T2/
```

Important tables:

```text
AllStates_T2_Components_Uncoupled_Coupled.xlsx
AllStates_Decay_Components_Uncoupled_Coupled.xlsx
```
